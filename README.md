# Kino

A movie discovery app built with React, Spring Boot and PostgreSQL.

### Tech stack
- React
- Bootstrap
- Spring Boot
- Spring Security + JWT
- PostgreSQL

### Description
The app supports:
- user registration and login
- browsing movies
- movie details
- ratings
- reviews
- admin user management

### Setup
Frontend:
1. In the `client` folder, run `npm install`.
2. Run `npm start`.

Backend:
1. In the `backend` folder, configure PostgreSQL in `src/main/resources/application.properties`.
2. Run the Spring Boot app with Maven.
